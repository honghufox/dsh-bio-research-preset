# 报告规范门控清单（references/reporting-guidelines.md）

用途：判定研究类型 → 取对应清单 → 逐项核对 → 缺失项直接写成 concern（附编号）。
所有清单均可在 EQUATOR Network 查到原始版本；本文件是审稿用的速查与「缺失长什么样」。

---

## 0. 先判定研究类型（判错门控 = 整份评审跑偏）

| 稿件自述 | 实际要核 | 常见误判 |
|---|---|---|
| 「prospective cohort」 | 是否有随访时间与失访 → 若无，实为横断面，用 STROBE | 用 CONSORT 要求随机化 |
| 「randomized」 | 随机单位是个体还是笼/孔/批 → 后者为整群随机，分析需对应 | 按个体随机的要求评 |
| 「case-control」 | 对照是否从同一源人群抽取 | 把便利样本当人群对照 |
| 「meta-analysis」 | 是否做了系统检索 → 否则只是叙述性汇总 | 用 PRISMA 全项要求 |
| 「RNA-seq validation by qPCR」 | qPCR 部分仍需 MIQE | 只核测序部分 |

## 1. ARRIVE 2.0（动物实验）

### 1.1 关键 10 项（缺任一项 → 至少 major）
| # | 项 | 缺失长什么样 | 怎么改 |
|---|---|---|---|
| 1 | 样本量 | 「n=6 per group」无估算依据 | 给效应量来源、α、power，或说明为探索性 |
| 2 | 纳入/排除标准 | 无；或事后剔除动物不说明 | 写明预设标准与剔除数量 |
| 3 | 随机化 | 「animals were randomly assigned」无方法 | 给工具/表格法、谁执行、何时执行 |
| 4 | 盲法 | 无；或只写「investigator blinded」 | 分层说明：给药、测量、数据分析各是否盲 |
| 5 | 结果测量 | 无主要终点；多终点未声明主次 | 预设主要终点 + 次要终点 |
| 6 | 统计方法 | 见 SKILL 第 3 节 | 检验 + 软件版本 + 校正 + 每图 n |
| 7 | 实验动物 | 「mice」无种系/来源/性别/年龄/体重 | 全称品系、供应商、周龄、性别及选择理由 |
| 8 | 实验步骤 | 关键操作不可复现（剂量、时程、麻醉） | 补可复现参数 |
| 9 | 动物福利 | 无伦理批号或批号格式不符 | 委员会名称 + 批号 + 与实验时间一致 |
| 10 | 数据可得性 | 「upon request」 | 给原始数据或明确豁免理由 |

### 1.2 高频附加问题
- 单性别研究未讨论性别差异（NIH/期刊政策常要求）。
- 饲养环境未报（群养/单笼、光周期、温度）→ 影响应激与结果。
- 肿瘤体积计算方式与测量者盲法未说明。
-  humane endpoint 未定义。

## 2. CONSORT 2010（RCT）

### 2.1 关键项
| 区块 | 必核 | 缺失长什么样 |
|---|---|---|
| 标题/摘要 | 标明 randomized | 摘要不说是 RCT |
| 注册 | 试验号 + 方案偏离 | 无注册号；注册晚于入组 |
| 方法 | 序列生成、分配隐藏、盲法层级、样本量依据 | 「随机分组」一句带过 |
| 参与者 | 纳入排除、场所、招募期 | 无流程图 |
| 干预 | 每组的精确方案（剂量/时程/依从性） | 只说药物名 |
| 终点 | 预设主要/次要终点 | 事后改主要终点（看注册记录对照） |
| 样本量 | 效应量来源与计算 | 无 |
| 随机化实施 | 谁生成、谁分配、谁入组 | 未说明 |
| 盲法 | 谁被盲、如何评估盲法成功 | 只写 double-blind |
| 统计 | ITT 为主、per-protocol 为辅、效应量 + 95% CI | 只报 p；只报 PP |
| 结果 | 每阶段人数、失访原因、不良事件 | 无失访说明 |
| 局限 | 外推边界 | 套话 |

### 2.2 审稿人必做的交叉核对
1) 注册号 → 查 registry，比对主要终点是否被改。
2) 流程图人数 → 随机数 = 分析数 + 失访数（能算出即合格）。
3) 效应量与 CI → 与 p 值是否一致。
4) 亚组分析 → 是否标注为探索性、是否做交互检验。

## 3. STROBE（观察性研究：队列/病例对照/横断面）

按区块核对（原清单 22 条，此处按审稿实操归并）：

| 区块 | 必核 | 缺失长什么样 |
|---|---|---|
| 设计声明 | 在标题/摘要/方法开头明确队列/病例对照/横断面 | 含糊称「observational study」 |
| 背景 | 预设假设 | 无假设，纯探索未声明 |
| 研究对象 | 纳入排除、来源人群、招募方式与日期 | 无招募流程与应答率 |
| 变量 | 结局、暴露、混杂、效应修饰变量的定义与测量 | 「 covariates included」不说哪些、为何 |
| 数据来源 | 谁测量、工具、信效度 | 自报问卷当客观指标且不讨论误分类 |
| 偏倚 | 选择/信息/混杂三类分别讨论 | 只写「可能有偏倚」 |
| 样本量 | 依据或事后精度说明 | 无 |
| 统计 | 混杂校正策略、亚组、缺失数据处理 | 缺失值直接删行不说明 |
| 参与者 | 流程图（入选→排除→分析） | 无流程图 |
| 描述性数据 | 各组基线、缺失数量 | 无缺失报告 |
| 结局数据 | 事件数、效应量（RR/OR/HR）+ 95% CI | 只报 p |
| 主要结果 | 未校正与校正模型都给 | 只给校正后 |
| 其他分析 | 亚组/敏感性分析 | 无敏感性分析 |
| 局限 | 具体偏倚的方向与量级 | 套话 |

**门槛提醒**：观察性研究的因果语言上限见 SKILL 3.10；若稿件用「effect of」，要求改为「association between」。

## 4. PRISMA 2020（系统综述/Meta 分析）

| 区块 | 必核 | 缺失长什么样 |
|---|---|---|
| 注册 | PROSPERO 号或声明未注册 | 无 |
| 检索 | 每个数据库的完整检索式 + 日期 + 限制条件 | 「we searched PubMed」 |
| 筛选 | 双人独立 + 分歧解决 + 排除理由 | 单人筛选 |
| 数据提取 | 提取表字段、双人核对 | 未说明 |
| 偏倚评估 | RoB 2 / ROBINS-I / NOS，逐研究报告 | 只写「quality was assessed」 |
| 效应量 | 模型选择（固定/随机）、异质性 I²、τ² | 只给合并 p |
| 发表偏倚 | 漏斗图/Egger（研究数 ≥10 时） | 无 |
| 敏感性分析 | 去一法、剔除高风险研究 | 无 |
| 流程图 | PRISMA 2020 flow diagram 四阶段数字 | 文字描述代替图 |
| 证据确定性 | GRADE（若做推荐） | 无 |

## 5. MIQE（qPCR / 表达定量）

| 项 | 必核 | 缺失长什么样 |
|---|---|---|
| 样本 | RNA 提取方法、RIN/DV200 值、gDNA 去除 | 无 RNA 质量 |
| 逆转录 | 酶、引物（oligo-dT/random）、投入量 | 无 |
| 引物 | 序列或引用、扩增子长度、熔解曲线 | 只有基因名 |
| 效率 | 标准曲线斜率与效率（90–110%） | 无效率 |
| 内参 | 选择依据 + 稳定性评估（geNorm/NormFinder） | 「GAPDH as control」无依据 |
| 重复 | 技术重复数 + 生物学重复数分别报 | 「in triplicate」含义不明 |
| 计算 | ΔΔCt 或标准曲线法、校正方式 | 只写 fold change |
| 统计 | 检验方法与 n | 无 |
| 数据 | Cq 原始值（补充材料） | 无原始 Cq |

**最常见 major**：生物学重复不足（n=2 细胞批次）而宣称组间差异；内参未验证。

## 6. 测序/组学数据门控

| 检查项 | 合格标准 | 不合格长什么样 |
|---|---|---|
| 数据入库 | GEO/SRA/ENA/PRIDE/MetaboLights 号，审稿期可用私有 token | 「available upon request」 |
| 元数据 | 样本表含分组、批次、临床变量 | 只有 GSM 号无分组说明 |
| 参考与版本 | 基因组版本（GRCh38/mm10）+ 注释版本 | 未写版本 |
| 流程与参数 | 工具名 + 版本 + 关键参数 + 随机种子 | 「standard pipeline」 |
| 代码 | GitHub/GitLab + Zenodo DOI（可引用快照） | 无 |
| 质量控制 | 每条样本的 QC 指标与过滤阈值 | 只写「low-quality reads removed」 |
| 批次/结构 | PCA/相关性矩阵展示组内与批次结构 | 无 |
| 多重检验 | FDR 方法与阈值、效应量阈值 | 只给 p |
| 验证 | 关键发现的正交验证（qPCR/IHC/独立队列） | 仅测序数据即下结论 |
| 统计设计 | 配对/重复测量结构是否进入模型（如 DESeq2 ~ donor + condition） | 忽略配对结构 |
| cut-off 优化 | 若用最优 cut-off，需校正或独立验证 | 用最优 p 值当结论 |

## 7. 数据可得性政策速查（写 concern 时直接引用）

| 数据类型 | 期望仓库 | 备注 |
|---|---|---|
| 转录组/芯片 | GEO / ArrayExpress | 需审稿期 token |
| 高通量测序原始读段 | SRA / ENA | BioProject + BioSample |
| 蛋白组/质谱 | PRIDE / MassIVE | 需 PXD 号 |
| 代谢组 | MetaboLights / Metabolomics Workbench | — |
| 结构 | PDB / EMDB | 需验证报告 |
| 代码 | GitHub + Zenodo DOI | 仅 GitHub 链接不可引用 |
| 人类个体数据 | 受控访问（dbGaP/EGA）+ 申请流程说明 | 「受保护」是合法豁免理由 |
| 材料 | 细胞株/质粒/品系，MTA 说明 | 无理由拒绝共享需说明 |

## 8. 门控结论怎么写（一句话公式）

> 「按 <清单名> 关键项 <编号>，稿件缺少 <具体项>（位置：<L/页码/表>）；该项影响 <可复现性/偏倚判断/结论强度>；请补充 <具体内容> 或说明无法提供的原因。」

示例：
> 按 ARRIVE 2.0 关键项 3 与 4，稿件未描述随机化方法与盲法实施层级（Methods L142–148）。这使 Fig 4 的治疗效应无法排除分组偏倚；请补充随机化工具、执行者与盲法层级，或说明该实验为探索性并相应下调结论。
