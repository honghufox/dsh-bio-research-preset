# 新电脑从零部署 DSH + 生物科研预设（bio-research）

> 适用：Windows。全程约 30–60 分钟（取决于网速）。核心步骤可用配套脚本 `setup-dsh-new-machine.ps1` 自动化。

## 第 0 步：网络准备（重要）

你的网络访问 `github.com` 直连不稳定（实测超时），但本机代理 `127.0.0.1:7897` 可用。**所有 git 操作前先设代理**：

```powershell
$env:HTTPS_PROXY="http://127.0.0.1:7897"; $env:HTTP_PROXY="http://127.0.0.1:7897"
```

- pip 若报代理错误（`ProxyError`），用 `$env:NO_PROXY='*'` 绕过
- pip 可换清华镜像加速：`-i https://pypi.tuna.tsinghua.edu.cn/simple`

## 第 1 步：安装 Node.js

1. 到 https://nodejs.org 下载 **LTS 版**（当前建议 v22+，本机用的是 v24 可用）
2. 安装后在 PowerShell 验证：
```powershell
node -v    # v22.x 或更高
npm -v
```

## 第 2 步：安装并启动 DSH

```powershell
npm install -g @deepseek-ai/dsh
dsh web
```
（首次运行自动初始化 web profile；也可用 `npx @deepseek-ai/dsh web` 免安装）

浏览器打开 **http://127.0.0.1:3080**：
1. **配置模型**：Settings（设置）→ Models → 填入你的 **DeepSeek API Key**（用旧电脑 Settings→Models 里同一把，或在 platform.deepseek.com 申请）
2. 建议先切到「标准模式」验证能正常对话

## 第 3 步：安装 bio-research 预设

```powershell
# 带代理克隆预设仓库
$env:HTTPS_PROXY="http://127.0.0.1:7897"; $env:HTTP_PROXY="http://127.0.0.1:7897"
git clone https://github.com/honghufox/dsh-bio-research-preset.git "$env:USERPROFILE\Desktop\dsh-bio-research-preset"

# 复制到 DSH 预设目录
New-Item -ItemType Directory -Force "$env:USERPROFILE\.dsh\.agent-presets" | Out-Null
Copy-Item "$env:USERPROFILE\Desktop\dsh-bio-research-preset" "$env:USERPROFILE\.dsh\.agent-presets\bio-research" -Recurse
```

**重启 DSH web**（关掉窗口重新 `dsh web`），新会话在预设选择器中选「生物科研模式」。

## 第 4 步：安装科研工具链（在新电脑的**普通终端**里执行，不要放进 DSH 沙箱）

### Python 3.11+（推荐 3.12，包兼容性最好）
到 https://www.python.org/downloads/ 安装，勾选 **Add to PATH**。

```powershell
pip install --user pandas numpy scipy statsmodels seaborn scikit-learn biopython lifelines vcfpy pyfaidx python-docx requests
```

### R 4.x
到 https://cran.r-project.org/ 安装（本机用 4.5.0）。

```r
# R 控制台执行
options(repos=c(CRAN='https://mirrors.tuna.tsinghua.edu.cn/CRAN/'))
install.packages(c('vcfR','survminer','survivalROC','timeROC','rms','cmprsk','forestplot'))
if (!requireNamespace('BiocManager', quietly=TRUE)) install.packages('BiocManager')
BiocManager::install('biomaRt')
```

### （可选）LaTeX / pandoc
- TinyTeX：https://github.com/rstudio/tinytex-releases/releases 下载 `TinyTeX-1-windows` 解压（约 70MB），装中文支持 `tlmgr install xeCJK ctex`
- pandoc：https://github.com/jgm/pandoc/releases 下载 windows-x86_64.zip 解压
- 技能里的 `<TINYTEX>` / `<PANDOC>` 占位符换成实际路径

## 第 5 步：启用 MCP 服务器

```powershell
# biotools（37 个生物信息工具）
Set-Location "$env:USERPROFILE\.dsh\.agent-presets\bio-research\tools\biotools"
npm install --ignore-scripts

# zotero（先禁用着，拿到凭证再启用）
Set-Location "$env:USERPROFILE\.dsh\.agent-presets\bio-research\tools\zotero"
npm install --ignore-scripts

# ncbi（E-utilities）
pip install --user ncbi-mcp "mcp>=1.0,<2"
```

编辑 `%USERPROFILE%\.dsh\.agent-presets\bio-research\agent.cordis.yml`：
- `NCBI_EMAIL: your_email@example.com` → 换成你的真实邮箱（NCBI 要求）
- （可选）申请 NCBI API Key 填入 `NCBI_API_KEY` 提速
- Zotero：到 zotero.org/settings/keys 建 Key，查 User ID，填入 `ZOTERO_API_KEY`/`ZOTERO_USER_ID`，删除该行 `disabled: true`

## 常见问题

| 问题 | 解决 |
|---|---|
| github.com 克隆/推送超时 | 先设 `$env:HTTPS_PROXY="http://127.0.0.1:7897"` |
| pip 报 ProxyError | `$env:NO_PROXY='*'` 后再装 |
| pip 在 DSH 沙箱内失败（Permission denied/chmod） | 在**普通终端**装包，不要通过 DSH 的 pwsh |
| 预设不出现 | 确认复制到 `.agent-presets\bio-research\`（注意是 `.agent-presets` 带点），并重启 DSH |
| `mcp__biotools__*` 工具缺失 | 检查 `tools\biotools` 是否执行过 `npm install --ignore-scripts`；服务器日志可在会话报错里看到 |
| 预设文件改动后不生效 | 重启 DSH web（standing mount 代际机制，改动需重启） |
| 版本兼容 | DSH 是 developer preview，若升级 dsh 后预设报错，重新 `git pull` 预设仓库 |
