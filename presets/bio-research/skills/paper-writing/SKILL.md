# 论文撰写

## 结构（IMRaD）
- Introduction：漏斗式——领域背景 → 未解决问题（gap）→ 本研究假设/创新点 → 主要结论预告
- Methods：可复现优先——材料/试剂/品系与来源、实验设计（样本量、分组、重复数）、统计方法（软件+版本+检验+校正）、数据可得性
- Results：按逻辑顺序、图先行（每图一个要点）；只报结果不解释；正文与图/表内容不重复
- Discussion：结果解释 → 与文献对比 → 局限 → 结论/展望；不重述 Results

## 标题与摘要
- 标题：<发现/现象> + <研究对象> + <关键方法/角度>；10–15 词；避免 "Novel / First" 等夸大表述
- 摘要：背景一句 → 方法概括 → 关键定量结果（带数值）→ 结论；期刊要求结构化时按 Background / Methods / Results / Conclusions
- 关键词 3–6 个，含 MeSH 风格术语便于检索

## 学术英语要点
- 时态：Methods/Results 用过去时；公认事实用现在时；Discussion 中总结自己的结果用过去时、一般性结论用现在时
- 语态：Methods 常用被动（was performed）；结果描述可用主动（we observed）
- 润色：避免 very/important/famous 等空泛词；用 significant/robust/consistent with；数字与单位格式（µM、10^6 cells/mL）；缩写首次出现给全称
- 逻辑连接词：however / therefore / in contrast / consistent with 的正确使用

## 参考文献
- 从 PMID/DOI 获取引文；格式化风格：Vancouver（序号制，生物医学期刊常用）、APA、Nature 风格
- 用户有 Zotero 时用 Better BibTeX 导出；否则直接给出格式化后的引用列表
- 引用真实性：只引用检索到的真实文献（用 biotools MCP 的 search_pubmed 验证），注明 PMID

## 投稿材料
- Cover letter：研究意义 + 新颖性 + 与期刊范围的契合 + 声明（未一稿多投等）
- 返修（Response to Reviewers）：逐条 point-by-point 回复；同意修改处说明改在哪，不同意处给出理由与文献支持
- 图表清单：Figure legends 完整（缩写定义、统计信息、n 数）

## 输出
- 本机未装 LaTeX：默认 Markdown（可转 Word）；用户需要 PDF/LaTeX 时协助安装 MiKTeX
- 交付时给出：正文、图表清单、参考文献、投稿说明
