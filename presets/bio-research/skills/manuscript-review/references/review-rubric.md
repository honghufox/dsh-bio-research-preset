# 评审判据与评分表（references/review-rubric.md）

## 1. 总体评分表（每项 0–2，满分 20；<14 不支持录用）

| # | 维度 | 0 分（不合格长什么样） | 1 分 | 2 分 |
|---|---|---|---|---|
| 1 | 问题—设计匹配 | 结论强于设计（相关数据写机制） | 匹配但边界未说明 | 设计与 claim 强度一致，边界明示 |
| 2 | 样本量与重复 | 无依据、n 以技术重复计 | 有 n 但无功效说明 | 有 a priori 功效分析 + 生物学独立重复 |
| 3 | 对照与偏倚控制 | 缺关键对照（vehicle/scramble/阳性） | 对照基本齐全，随机化/盲法不全 | 随机化+盲法+对照齐全且有方法描述 |
| 4 | 统计报告完整性 | 只给 p<0.05 | 有 p 与检验名，缺 CI/效应量 | p 精确值 + 效应量 + 95% CI + 校正方法 |
| 5 | 报告规范门控 | 无 checklist、关键项大面积缺失 | 有 checklist 但若干关键项缺失 | 门控全覆盖，缺失项有说明 |
| 6 | 图表自洽 | 正文与图冲突、legend 缺要素 | 小瑕疵 | legend 七要素齐、统计标注清楚 |
| 7 | 数据/代码可得 | 「upon request」且无例外理由 | 部分可得 | accession + 代码 + 参数齐全 |
| 8 | 因果措辞 | 观察性写 causes | 个别句越界 | 全文动词与设计匹配 |
| 9 | 局限讨论 | 套话（"larger cohorts needed"） | 泛泛但相关 | 具体到本研究的具体偏倚方向与影响 |
| 10 | 引用与文献关系 | 引用不支持所述、漏掉最接近的工作 | 基本正确但新颖性定位模糊 | 与最接近工作差异清楚、引用真实 |

## 2. 四档 recommendation 的边界判据

| 边界 | 归入 Minor | 归入 Major | 归入 Reject |
|---|---|---|---|
| 缺的是「怎么写」 | ✅ | | |
| 缺的是「一个能做的实验/分析」 | | ✅ | |
| 缺的是「设计上不可能补」 | | | ✅ |
| 结论被自家数据否定 | | | ✅ |
| 有明确不端证据 | | | ✅（并走机密渠道） |

判定先后：先问「结论是否可能成立」，再问「证据是否充分」，最后问「表述是否准确」。
第一问为否 → 直接 Reject，不必再列 minor。

## 3. Confidence 量表

| 值 | 含义 | 报告里要加的说明 |
|---|---|---|
| 5 | 本方向核心，读过全部关键文献 | 无 |
| 4 | 熟悉方法但不熟悉该疾病模型 | 「方法学部分在本人专长内」 |
| 3 | 一般生物医学训练可评 | 「统计细节建议由统计审稿人复核」 |
| 2 | 仅能评写作与逻辑 | 「建议增补 <领域> 专家」 |
| 1 | 明显超出专长 | 应拒审，而非给低分 |

## 4. severity 定义（用于给每条 concern 定级）

| 级别 | 定义 | 处置 |
|---|---|---|
| Blocking | 不做则核心结论不成立 | gating，必须出现在 decision letter |
| Substantial | 影响可信度/可复现性，但不否定结论 | gating 或 strong recommendation |
| Moderate | 影响读者判断或部分结论 | non-gating，需在返修中处理 |
| Editorial | 格式、语言、引用格式 | non-gating，可交排版 |

## 5. 「不合格」措辞库（把模糊评价换成可执行要求）

| 模糊写法 | 替换为 |
|---|---|
| 统计方法不清楚 | 请说明 Fig 2 四组比较所用检验、是否校正多重比较、n 的定义 |
| 数据不足以支持结论 | 摘要 L38 的因果表述超出横断面设计的支持范围；请改为相关性表述或补充干预实验 |
| 图片质量差 | Fig 3A 分辨率低于 300 dpi，坐标轴无单位，请重制 |
| 新颖性不足 | 本文与 <作者, 年> 的差异仅在 <细胞系>，未提供机制或转化增量 |
| 讨论不充分 | Discussion 未讨论 <具体偏倚：健康工人效应/选择偏倚> 对 <具体结论> 的影响方向 |
| 样本量小 | n=3/组无法检出 <效应量> 以下的差异（power 0.8, α=0.05），请给出功效依据或降级结论 |

## 6. 快速分流：先看这三处
1. 摘要最后一句的动词 → 判断 claim 是否超出设计（3.10 阶梯）。
2. Methods 里 n 的定义 → 判断伪重复（3.4）。
3. 数据可得性段 → 判断可复现性与期刊政策合规。
这三处通常在 10 分钟内决定档位，之后再补细节。
