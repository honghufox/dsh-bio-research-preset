# lint_manuscript.py 实测输出摘录

> 目的：记录离线稿件体检脚本在**真实稿件**上的实际行为，供 P7 一致性终检（门控 G2/G4/G5）与
> 后续回归对照。以下命令、计数、逐条输出均为 2026-11-06 在 Python 3.10.2 / Windows 下的真实运行结果，
> 未做修饰（仅把过长的片段按原输出截断保留 `…`）。

## 1. 复现命令（真实路径）

```bash
# 单节：样章（36 条正文引用全部命中 165 条 refs）
python lint_manuscript.py --input "E:\2026\毕业论文综述部分撰写\drafts\1.2.4_样章.md" \
  --refs "E:\2026\毕业论文综述部分撰写\refs\_used_in_review.md"

# 单节：证据章
python lint_manuscript.py --input "E:\2026\毕业论文综述部分撰写\drafts\1.2.5.md" \
  --refs "E:\2026\毕业论文综述部分撰写\refs\_used_in_review.md"

# 全稿（9 个分节）：跨节引用闭环 + 图表定义汇总 + 图片目录
python lint_manuscript.py --input "E:\2026\毕业论文综述部分撰写\drafts" \
  --refs "E:\2026\毕业论文综述部分撰写\refs\_used_in_review.md" \
  --figures "E:\2026\毕业论文综述部分撰写\figures"
```

三次运行退出码均为 **1**（存在 error；warn/info 不影响退出码）。内置 `--selftest`：**25/25 通过**。

## 4. 最值得注意的三条真实发现

1. **图表题注缺失是真实阻断项**：`1.2.4` 的 `表1/图1`、`1.2.5` 的 `表2` 都只有行内引用，Markdown 表格本身
   没有题注（`表 N …` 行首）。加上 `--figures` 后图 1–4 因文件名获豁免，error 从 5 降到 2，剩下的正是
   两张无题注的表——与人工看稿结论一致：图形文件存在，但表题/图注文字没写进正文。
2. **引用闭环抓到两类真实引用错误**：全稿模式下 165 条 refs 仅 5 条从未被引用；其中
   `Nesse 1991` 实为 refs 第 150 条（第一作者 Williams）的**第二作者**，`Le 2003` 应为
   `Le Poul 2003`（姓氏截断）。这两类错误（按第二作者引用、姓氏不完整）逐篇读稿很难发现，
   是引用闭环规则最划算的产出。
3. **分节稿存在复制粘贴级重复与格式残留**：`1.2.4` 第 11/17 行共享 12 字短语
   「的绝大部分以酯键锚定于细」；全稿模式还检出 `1.2.5`、`1.2.6`、`1.2.7` 三处 `**。**` 游离加粗
   （正文被误插入空强调标记），以及 `1.2.6` 内「碳水化合物含量蛋白含量与」等跨段复制。

## 5. 误报与已知局限（来自实测）

- **R2 缩写**：基因/受体符号（`GPR109A`、`NFAT`、`MAPK`、`AMPK`、`HMGCR`、`ARE`、`LXR`…）默认只给
  info/warn，作者通常不会逐个展开；建议在 `style-guide.md` 建立白名单，用 `--config` 的
  `abbreviation_whitelist`/`registered_abbreviations` 收敛。文末「注：缩写表」不算首次定义，
  故 `IIS/SOD/CAT/MDA` 仍会 warn（若团队约定接受文末缩写表，可置 `treat_note_as_definition`）。
- **R5 措辞**：`1.2.5:7`「解释力度显著高于…」这类**评价性**比较不是统计显著性，仍会被标 warn；
  `显著` 的语用边界只能人工复核（脚本已排除「无论多么显著」这类修辞）。
- **R1 图表**：只有图注/表题内容进入 Markdown 才能被识别；图在 `.docx`、表题在 Word 域中时需要
  `--figures` 或人工确认。`--figures` 只按文件名免除告警，不核对题注文字。
- **R7**：中文按 12 个汉字 ≈ 8 个词近似（不分词），单节文件退化为"段间重复"；表格/公式块可能误报。
- **R6**：按「第一作者姓 + 年份」匹配，作者索引可识别非第一作者；同名不同人、机构作者、
  中文姓名缩写仍可能误配。单节 + 全稿 refs 时未引用条目自动降为 info（避免 130+ 条噪音）。
- 不做拼写/语法/参考文献格式/期刊模板检查；这些应由 `verify_refs.py` 与人工评审承担。
